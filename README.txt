# AIM RANK — app de treino Valorant + Aimlabs

## O que inclui
- Painel com XP, treinos concluídos e conquistas
- Catálogo inicial de tarefas Aimlabs e exercícios dentro do Valorant
- Registro manual de pontuações e conquistas
- Perfil, elo, sensibilidade, objetivo e tema claro/escuro
- Backup JSON e restauração
- Manifesto PWA e service worker para instalação em dispositivos compatíveis

## Instalar no iPhone
Para aparecer como app na Tela de Início, publique esta pasta num endereço HTTPS. Um jeito gratuito é usar GitHub Pages:
1. Crie uma conta no GitHub, se necessário, e crie um repositório público chamado `aim-rank`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No repositório, abra Settings → Pages.
4. Em Build and deployment, selecione Deploy from a branch, escolha `main` e `/ (root)`, depois Save.
5. Aguarde o endereço HTTPS ser publicado.
6. Abra o endereço no Safari do iPhone → Compartilhar → Adicionar à Tela de Início → Adicionar.

Os nomes exatos dos menus podem variar. A versão hospedada usa armazenamento local do Safari; os dados não sincronizam automaticamente entre dispositivos. Exporte backups no app para guardar seus registros.

## Observações
- É um app pessoal de registro, não se conecta automaticamente ao cliente Valorant nem ao Aimlabs.
- O catálogo do Aimlabs é inicial, não uma cópia completa ou oficial de todas as tarefas disponíveis.
- Não coloque credenciais ou informações sensíveis no app.
